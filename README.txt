EDUSHEET - BẢN ĐÃ SỬA CHỦ ĐỀ SÁNG/TỐI/TỰ ĐỘNG

Cấu trúc thư mục:
- index.html
- categories.html
- generator.html
- faq.html
- contact.html
- css/style.css
- js/main.js
- js/data.js

Cách sử dụng:
1. Giải nén file ZIP.
2. Mở thư mục EduSheet_chu_de_da_sua trong VS Code.
3. Sao lưu dự án cũ trước khi thay thế nếu bạn muốn giữ bản gốc.
4. Chạy index.html bằng Live Server.
5. Chọn Sáng / Tối / Tự động ở thanh điều hướng.
6. Lựa chọn được lưu và áp dụng chung cho cả 5 trang.

Tự động dựa vào cài đặt giao diện sáng/tối của hệ điều hành/trình duyệt.
